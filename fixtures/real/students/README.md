# Real Student Fixture Evidence

These fixtures preserve real student DOCX inputs and their human-reviewed content recognition notes for future regression work.

They are not used as Bootstrap PASS fixtures because the Bootstrap profile intentionally treats images and other unsupported visible objects as `UNKNOWN`.
