# real-core-v0 Eval Profile

`real-core-v0` 固定第一批真实学校评测组合：

- 三个目标模板；
- 三份学生源文档；
- 九个目标模板 × 学生文档转换 case。

这个目录只登记 profile 组合。原始输入在 `inputs/`，已签收 expected 在
`standards/targets/`、`standards/students/` 和 `standards/cases/`。

当前状态：源事实已经绑定到标准和 expected；覆盖率仍可能因为 Word 页面图像证据、
阶段 verifier 或真实输出质量问题返回 `FAIL` / `UNKNOWN`。
