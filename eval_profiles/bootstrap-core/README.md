# Bootstrap Core Eval Profile

`bootstrap-core` 定义最小可运行的 demo-school 评测组合。

- 组合配置在 `profile.yaml` 和 `src/docfit/harness/profiles.py`。
- 原始输入在 `inputs/targets/demo-school/` 和 `inputs/students/bootstrap-demo-*/`。
- expected 本体在 `standards/cases/demo-school__bootstrap-demo/v1/`。
- 目标模板标准、golden 和例外在 `standards/targets/demo-school/v1/`。

这个目录不存放原始输入，也不存放 expected 文件。
