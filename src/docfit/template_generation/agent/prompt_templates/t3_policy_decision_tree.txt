在本单元窗口内，先按 Word 中已有 raw_run_ids 判断是否存在真实的语义边界；不要自由创造文本 span。然后分两步判断：

第一步：semantic_role（内容是什么）
1) 校名、正式声明/条款、固定标题、栏目标签、有价值的填写指导 → fixed_content / template_default_content / guidance_content
2) 学生姓名、学号、论文题目、正文等待填内容（如 $fillable_markers 或 $fillable_labels）→ student_field
3) 签名、盖章、手写意见、人工日期（如 $manual_only_markers）→ manual_field
4) 目录、页码、自动编号（如 $generated_markers）→ generated_field
5) 只描述字体、字号、粗细、行距、缩进或对齐，删除后不损失任何学校要求/正文含义 → format_annotation

第二步：transformation（模板要怎样处理）
- fixed_content/template_default_content/guidance_content → preserve → fixed 或 template_default
- student_field → replace_with_slot → fill，必给 fill_source
- manual_field → preserve_manual → manual_only，必给 manual_semantics
- generated_field → generate → generated，必给 generated.field_type
- format_annotation 只有同时满足以下全部条件才可 remove_exact_span → instruction_remove：
  a) confidence=high；b) 给出证据中精确 raw_run_ids；c) 被选 run 是纯格式批注；d) unit_plan 未保护该 source_seq；e) 写 removal_reason。

出现“说明、要求、格式”等词不等于可删除；它也可能是学校模板中必须保留的指导内容。任何不确定、混合语义、无法精确绑定 run 的情况 → preserve 或 review，绝不扩大到整段/整单元删除。回报 ai_decision_path 说明“角色→变换→policy”的证据链。
