T2 的目标：从学校论文 Word 模板中建立顶层结构单元清单。每个 item 表示一个可独立处理的连续结构块，并用 source_seq_refs 标出它覆盖的文本节点；分页策略描述生成新模板时这个单元如何开始、是否独占页面范围。

执行流程：
1. 页面草图：先查看页面图和 page_summary，记录每页的独立块、连续块、页首标题、整页表单、声明页、目录页、摘要页、正文页和后置表单页。
2. 边界绑定：再读 rows，把页面草图中的每个块绑定到准确的 source_seq 范围。source_seq 是最终边界坐标。
3. 单元判定：候选块需要同时具备独立标题或稳定版式、独立功能、后续内容区域或表单区域、与前后块的边界证据。
4. 拆分/合并：先得到顶层单元边界，再进入分页策略判断。
5. 分页策略：对每个已确定单元，只判断 page_policy.start 和 page_policy.scope。
6. 证据检查：每个 item 的 source_seq_refs 来自 rows，evidence_refs 引用实际使用过的 source_seq/page/break/visual 证据。

你会拿到这些事实：
- rows：按文档顺序排列的文本节点。每行有 source_seq、可见文字、页号、渲染定位、flow 类型、样式名，以及对齐、字号、加粗、tab/leader 等文本事实。source_seq 是你输出边界的唯一坐标。
- page_summary：真实渲染后每页的 first_source_seq / last_source_seq / text_items，用来判断某个结构是否单独成页或跨页。
- break_facts：分页符或分节符，已对齐为 after_source_seq。它是分页证据，不是单元答案。
- visual_evidence：页面图片引用；同一消息里会附带这些页面图。先看图片获得页面级结构印象，再回到 rows 绑定准确的 source_seq。图片负责版面判断，Word 文字负责最终身份和边界。
- page_thumbnails：页面图片的稳定 hash/宽高/页号元数据，供 evidence_refs 引用。

单元成立标准：
- 视觉上像独立块：从新页或页顶部开始，标题居中/加粗/大字号，前后有明显空白，或整页是表单、声明、目录、摘要等固定块。
- 语义上可独立理解：封面、版权/诚信/原创性/授权声明、主目录、图目录、表目录、正文题名信息、中英文摘要、正文主体、参考文献、附录、致谢、学术成果、任务书、开题报告、答辩记录、成绩表等。
- 功能上可独立处理：有的单元要保留原样，有的由系统生成，有的等待学生填写，有的只是后置固定表单；T2 只识别单元和分页，不判断 T3 元素策略。
- 边界上通常连续：一个单元应覆盖一段连续 source_seq。只有模板真的把同类结构分开出现时，才拆成多个 item。

拆分/合并工作流：
1. 先看页面图和 page_summary，建立“每页有哪些独立块”的草图：页顶部标题、独立表单、声明页、目录页、摘要页、正文页、后置表单页。
2. 再读 rows，把每个视觉块绑定到 source_seq 范围。Word 文字是最终边界坐标；图片只帮助判断版面和独立性。
3. 遇到候选标题时，检查它是否同时满足“独立标题 + 独立功能 + 后续内容区域/表单/条目/签名区 + 与前后块有边界”。
4. 相邻内容应拆成多个单元，当它们有不同的独立功能，并且各自有标题或内容区域；同页不是合并理由，同属一个大类也不是合并理由。
5. 相邻内容应合并到同一单元，当后面的文字只是该单元的正文、条目、说明、空行、格式要求、签名行或字段行；标题样式相似不是拆分理由。
6. 对边界没把握时，把可确定的连续范围输出为高/中置信度；无法判断的 source_seq 留 unknown_unit。

典型正确标准：
- 一个独立生成型列表块，有页顶部标题、条目、leader dots 或页码，即使它不是正文内容，也应作为目录类单元。
- 两个相邻块即使在同一页，只要各自有独立标题、独立说明/签名/表单区域和不同功能，就应在第二个标题处拆分。
- 一个题名区只有在它自己形成独立元数据块时才是正文题名信息；通常应能看到题名加作者/学生、导师/指导老师、学院/单位等字段，并与后续摘要或正文有清楚边界。
- 摘要、正文、参考文献、附录等长内容内部可以有多级标题和格式说明；这些是单元内部结构，不是新的 T2 顶层单元。

典型错误标准：
- 只因文字中出现“正文、摘要、参考文献、附录”等词就开启对应单元。
- 只因两个块在同一页、同属声明类或同属表单类，就合并为一个单元。
- 只因某行使用标题样式、居中、加粗或大字号，就当成顶层单元；顶层单元还需要独立功能和边界。
- 格式说明、空行说明、字体说明被单独作为真实单元，或按说明文字中的关键词归类。
- 目录条目里的标题文字被当成真实单元开头。

目录类判断：
- 目录、图目录、表目录只要在模板中独立出现，就是单元。它们通常有独立标题、条目列表、leader dots/页码、生成型功能，并经常独立分页。
- 目录条目里的“摘要、Abstract、正文、参考文献、致谢、附录”等只是目录内容，不是对应真实单元的开始。只有离开目录块、进入真实页面/标题后，才打开真实单元。

格式说明和空行判断：
- 格式说明、空行说明、字体/字号/居中/加粗说明通常是服务于附近结构的模板说明或占位说明。归属判断看它服务的前后结构，而不是说明文字里的关键词。
- 这类说明应并入它服务的最近结构：看它前后连接的是题名元数据、摘要、正文、参考文献还是表单，而不是看说明文字里出现了哪个单元名称。

正文主体判断：
- body_main 从真实正文内容或正文内部标题体系开始，例如“1 前言”“第一章”“研究背景”“绪论”等；正文内部的一级/二级/三级标题持续归入 body_main。
- 图目录、表目录、参考文献、附录、致谢等在正文之后重新形成独立单元时，应按真实边界切开。

分页判断方法：
分页策略描述的是“生成新模板时这个单元应该如何占用页面”，不是描述每个段落样式，也不是简单复述当前模板刚好显示在哪一页。按下面顺序判断。

步骤 A：判断 start，也就是这个单元开始时是否应另起页。
- document_start：文档第一个单元。
- new_page：单元标题或首个内容在新页页首，或 break_facts 显示前一单元结束后有分页/分节，或同级单元重复呈现“页首开始”的模式。
- same_page_allowed：它明确接续上一单元，且共享同一页是该模板结构的一部分。
- unknown：没有足够证据。没有 break_facts 不等于 same_page_allowed；分页可能来自渲染流、样式或表格布局。

步骤 B：判断 scope，也就是这个单元是否应独占自己的页面范围。
- single_page_exclusive：短的固定页或原子块，应尽量整体留在单页，例如封面、短声明、单页固定表单。它通常不应自然跨页。
- page_range_exclusive：这个单元可以跨多页，但这些页应作为该单元自己的连续页段，不应与前后顶层单元共享。典型信号是生成型目录/图目录/表目录、多页固定表单、任务书、开题报告、记录表、审批表、成绩表等；它们可能跨页，但仍是一个独立页段。
- shareable_flow：普通论文内容流。它可以从新页开始，也可以跨页，但不是固定独占页段。典型信号是摘要、正文主体、参考文献、附录、致谢、学术成果等可随内容自然增长的章节块。
- unknown：当前证据无法区分固定页段和普通内容流。

分页判断的典型正确标准：
- 单元从新页开始，只能说明 start=new_page；不能自动推出 scope=page_range_exclusive。
- 摘要、正文、参考文献、附录、致谢这类内容流，即使页首开始，通常仍是 shareable_flow。
- 多页固定表单或生成型列表，即使跨多页，也可以是 page_range_exclusive；跨页不等于普通内容流。
- 一个短声明或封面如果视觉上是固定原子页，通常是 single_page_exclusive；但两个声明同页连续出现时，仍应按各自标题和功能拆成两个单元。

分页判断的典型错误标准：
- 把“有分页符/页首标题”直接等同于“独占页段”。
- 把“内容跨多页”直接等同于“普通 shareable_flow”。
- 因为没有 break_facts 就把 start 写成 false；没有机械分页证据时应结合图片、page_summary 和同级模式判断，仍不足才写 unknown。
- 在分页策略阶段重新用目录条目、格式说明或小标题打开新单元。

输出时：
- 每个非 unknown item 必须有 unit_id、source_seq_refs、confidence、分页字段和 evidence_refs。
- source_seq_refs 必须来自 rows，尽量覆盖完整连续边界；不确定的 source_seq 留给 unknown_unit。
- 不需要输出 order 或序号；系统会按每个 item 的最小 source_seq 生成顺序。
- 不得读取、猜测或引用任何代码侧 unit_map、merged、标准答案或评测结论。
