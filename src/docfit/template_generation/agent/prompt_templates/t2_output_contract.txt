只返回一个 JSON 对象，不要输出 Markdown、解释或额外字段：

{
  "units": [
    {
      "unit_id": "cover",
      "unit_name": "封面",
      "boundary": {
        "start_page": 1,
        "end_page": 1
      }
    }
  ]
}

严格要求：

- 顶层只能有 units。
- 每个单元只能有 unit_id、unit_name、boundary。
- boundary 只能有 start_page、end_page，页码为从 1 开始且包含首尾的整数。
- units 按页面顺序排列，第一页必须从 1 开始，最后一个单元必须覆盖最后一页。
- 相邻单元必须首尾连续，不能有页面遗漏或重叠。
- unit_id 使用小写英文 snake_case，并在同一文档内唯一。
- 不得输出 source_seq、source_ref、page_policy、confidence、reason、evidence 或其他字段。
