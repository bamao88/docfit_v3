# Hunan Agricultural v1 Evidence Package

This directory stores the real template source, legacy source, and human review evidence for a future MVP school standard.

The converted `.docx` is the future Stage 1 primary input. The original `.doc` is retained as provenance only.

It is not yet a runnable signed standard for `docfit eval e2e`; the Bootstrap implementation only signs `demo-school`.

Inputs:

- `inputs/school-hunannongye-requirement.docx`
- `inputs/school-hunannongye-requirement-legacy.doc`
- `inputs/school-hunannongye-template-review.txt`
